Расписание жителей деревни
В input.txt записан распорядок дня жителей деревни в формате Имя_NPC;Час_начала;Час_конца;Локация 
(например: Кузнец_Бодб;8;16;Кузница, Кузнец_Бодб;16;22;Таверна). Программа должна взять текущий игровой час 
(current_hour), проанализировать файл и вывести в output.txt сводку: кто из жителей и в какой локации находится прямо сейчас.
Если для какого-то NPC в текущий час не найдено подходящего интервала — вывести напротив его имени статус [Спит дома].
